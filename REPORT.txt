1. INTRODUCTION
--------------------------------------------------------------------
This project implements a complete CI/CD pipeline for a small AI 
application. The goal is to ensure that every change to the bot is 
automatically tested, evaluated for correctness, and validated against 
a groundedness threshold before being accepted. The pipeline enforces 
quality, prevents regressions, and demonstrates DevOps principles such 
as automation, least privilege, and continuous verification.

The application consists of a simple question‑answering bot with fixed 
responses for school safety procedures. The pipeline evaluates the bot 
using deterministic unit tests and a similarity‑based eval gate.

3. BOT IMPLEMENTATION (src/bot.py)
--------------------------------------------------------------------
The bot provides deterministic responses for three required questions:

- Lockdown procedure  
- Fire drill procedure  
- Late policy  

These responses are intentionally simple and fully grounded in the eval 
dataset. The bot is designed to be predictable so that unit tests and 
eval scoring remain stable.



4. UNIT TESTS (tests/test_bot.py)
--------------------------------------------------------------------
The test suite verifies that the bot returns the exact expected strings 
for each question. These tests ensure that basic regressions are caught 
before the eval gate runs.

Tests include:
- test_lockdown()
- test_fire_drill()
- test_late_policy()
